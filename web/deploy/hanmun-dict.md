# 빠른 한문 입력기 사전 (hanmun-dict.json)

빠른 한문 입력기(https://hanmun.j-segrc.workers.dev)에 쓰이는 사전 전체입니다.
주소로 바로 불러올 수 있습니다: https://hanmun.j-segrc.workers.dev/hanmun-dict.json
(UTF-8 JSON 한 덩어리, 약 1.3MB)

## 구조

모든 목록은 **앞에 있을수록 자주 쓰이는 것**입니다. 객체의 키 순서도 빈도 순입니다.

| 키 | 형태 | 내용 |
|---|---|---|
| `c` | `{독음: "한자들"}` | 한 글자 독음 → 그 음의 한자들 (문자열, 글자 하나씩) |
| `p` | `{독음: "한자들"}` | 한문에서 특히 자주 쓰는 글자 (한문 우선 순위) |
| `w` | `{독음: ["漢字", …]}` | 현대 한자어 |
| `cw` | `{독음: ["漢字", …]}` | 고전 어구·이두 (직접 정리) |
| `kw` | `{독음: ["漢字", …]}` | 조선왕조실록·승정원일기에서 뽑은 어구 |
| `gw` | `{독음: ["漢字", …]}` | 논어·맹자 구절 |
| `u` | `{한자: 횟수}` | 실록·승정원일기 말뭉치의 글자 빈도 |
| `f` | `{한자: "한자들"}` | 그 글자 바로 뒤에 자주 오는 글자들 (문맥 순위용) |
| `m` | `{한자: "훈음"}` | 한 글자 훈음 (예: `"可": "옳을 가"`) |

- 독음은 완성형 한글이고, 두음법칙은 적용된 형태입니다(예: `이`로 李·理).
- 확장 한자(서로게이트 쌍)가 섞여 있으니 `c`·`p`·`f` 문자열은 코드포인트 단위로 나누세요 (JS: `[...s]`).

## 입력기에서 순위를 매기는 방법 (참고)

한 글자 후보는 다음 점수로 정렬합니다.

    점수 = log(u[글자] + 1)
         + (앞 글자 f 목록에 있으면 4 + (80 - 그 위치) / 16)
         + (p[독음]에 있으면 1.5)
         − (말뭉치에 없으면 50)

여러 글자 독음은 `cw → kw → gw → w` 순서로 찾고, 같은 단어는 한 번만 보여 줍니다.
논어·맹자 구절(`gw`)은 구절 독음의 1/3을 넘게, 2음절 이상 쳤을 때만 미리 보여 줍니다.
자세한 구현은 저장소 `web/src/engine.js`(웹)와 `windows/src/Engine.cpp`를 보세요.
